# 数据源与核验指南

版本：0.1.0；更新：2026年10月28日。以下是研究候选目录，不是已经实现的连接器或数据订阅。每次任务重新核访问、公布日期、使用许可、地域和口径；动态页面可读不代表其数据API可用。

## 本轮入口级检查记录

2026年10月28日，本轮主Agent通过网页工具读取了巨潮公开首页和SEC官方API说明；国家统计局首页超时，中国政府网政策入口返回403。检查仅覆盖入口，不证明具体数据、付费权限、完整覆盖、自动采集或真实案例已验证。失败不代表源不存在；本轮没有绕过限制。后续任务可用可访问的官方原文、合法下载或用户授权材料，并明确取得方式与时点。

## 每个来源的最小动作

1. 定位原始发布者与原始文件；保存URL/离线引用、页/表/段、发布时间、获取时间、统计期和地域。
2. 确认获取时可用信息与决策截至日一致。历史分析不能使用当时未公布或未取得的材料冒充当时已知。
3. 按文件原件计算SHA-256并记录；摘要只证明字节相同，不认证文件真实。没有原件时保留实际证据级别。
4. 查找修订、重述和相反材料。转载追溯共同origin，不因多个站点出现而增加独立证据数。
5. 只提取所需事实，遵守源方许可与访问规则。没有访问权不绕过登录/反爬，不购买数据，不将授权私有资料自动上传第三方。
6. 写出「公开事实→适用边界→本业务传导机制→反证/未知→下一核验」。无法完成传导链时输出待验证假设。

## 有效期与刷新

`expires_at`是本次判断采用的复核截止日，由来源特征、决策期限与变化速度设定并说明理由，不能假称源方保证。政策按有效期和申报窗复核，财报遇重述重开，经营数据按实际更新周期。旧数据可能仍可作历史比较，但不得作为当前关键主张的fresh支持。是否创建持续监控由用户另行授权；本Skill没有后台刷新器。
