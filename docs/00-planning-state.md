版本：0.1.0；日期：2026年10月28日；状态：REVIEW_PENDING。实际作者：Codex 子 Agent `wealth_blueprint`。本文件是本仓规划状态入口；PRD 唯一现行正文为 [01-prd.md](01-prd.md)。

## 目标与本轮授权

为已有生意和待选择的经营方向建立财富与经营机会雷达：结合授权经营数据、线上线下观察、官方统计、财报和政策，形成可追溯的机会判断、风险、现金情景与下一步验证行动。

本轮用户明确要求直接推进完整规划、公开可安装 Skill、安装验证，并另行审核和修复现有产品。由此连续产出阶段0–6的草案；没有据此伪造逐阶段确认。规划文件和 Skill 不是已经建成的雷达应用、自动采集平台、交易系统或获利证明。现有产品修复在独立分支处理，本仓不能替代其修复与验收证据。
