# Wealth Architect PRD

版本：0.1.0；日期：2026年10月28日；状态：REVIEW_PENDING；上游：[规划基线](00-planning-state.md)。作者：Codex `wealth_blueprint`。这是产品规格，不是已实现功能清单。

## 定位与用户任务

为经营者提供有证据、可反驳、能落到小规模行动的机会判断。核心问题是「基于我现有的业务、资源和风险承受能力，下一笔时间与资金更值得投在哪里，需要先验证什么」。财富部分涵盖经营现金、资本占用、风险集中与可支配资源；证券选择或具体个人配置只在用户明确提出、背景充分且适用证据齐全时研究，不推导交易指令。

首要用户是已有业务的小企业经营者；次要用户是比较业务方向的创业者与为多个项目分配资源的负责人。三者目前是基于任务的设计人群，尚无访谈证明。现有替代方法包括人工查公告并维护表格、请行业顾问出报告、直接使用通用研究助手；应以同一决策任务比较可追溯性、耗时和遗漏，而不是凭产品名宣称胜出。

| 故事 | 用户故事 | 成功与反例验收 |
|---|---|---|
| US-01 | 作为已有生意的经营者，我想结合自身经营指标和外部变化筛选机会，以便决定先做哪项小试验。 | AC-01：输出最多3个候选，均有与本业务的因果链、反证、约束、成本区间和下一验证；只有宏观增速时不能称已有可投资机会。 |
| US-02 | 作为跨地区经营者，我想知道政策和统计对我的主体是否适用，以便避免把全国利好误当本地可领取收益。 | AC-02：核地域、主体、资质、申报窗、有效期和实际执行条件；任一关键项缺失显示待核验，不计入确定现金流。 |
| US-03 | 作为资源有限的负责人，我想比较现金回收与最坏损失，以便先选择损失可控的行动。 | AC-03：展示收入、毛利、固定/可变支出、投入、营运资金、回款账期和退出成本；悲观/基准/乐观有明确参数来源；不凭高分越过现金底线。 |
| US-04 | 作为报告复核者，我想从结论回到当时可得原始证据，以便发现过期、冲突和重复转载。 | AC-04：每项关键主张有证据ID及定位；冲突不静默平均；按决策时点排除未来才公布的信息；后续修订保留旧版本。 |
| US-05 | 作为持续经营者，我想记录真实试验结果并更新判断，以便停止无效投入。 | AC-05：保存原报告与预算/停止条件；新增反馈生成新修订并说明变化，不改写旧预测冒充准确。 |

## 范围与优先级

本轮交付形态为 Agent Skills 标准包：按授权使用当前客户端的浏览器/连接器或用户材料，执行研究流程，输出报告与结构化证据包；自带确定性检查和合成测试。安装不启动后台进程，不自动拥有账户和数据访问权。

| 需求 | 优先级 | 输入→处理→输出 | 规则与依赖 |
|---|---|---|---|
| REQ-01 决策约束 | P0 | 生意/地域/客群/现状/预算/时限→识别缺口→决策简报 | 对影响范围和安全的缺项询问；非关键缺项标假设后继续；禁止索取无关私有资料。 |
| REQ-02 多源证据 | P0 | 官方/财报/授权账目/线下记录→口径与来源核验→证据台账 | 使用[证据模型](../references/evidence-model.md)；访问失败保留UNKNOWN与可行补证路径。 |
| REQ-03 机会与反证 | P0 | 证据+业务约束→需求/供给/竞争/政策/财务/能力分析→候选 | 区分市场变化、可触达客户、单位经济性与本主体执行能力；不以财报增长推出行业总增长。 |
| REQ-04 现金与风险 | P0 | 明示参数→复算情景→现金缺口/敏感参数/停止投入线 | 单位、币种、税前税后、含税与否保持一致；缺数不补零；补贴未确认不得当到账。 |
| REQ-05 决策包与恢复 | P0 | 候选+风险→优先小试验/观察/拒绝/暂缓→报告+结构化输出 | 记录版本、截至日期、局限、证据和观察动作；更新前保留旧版。 |
| REQ-06 持续雷达 | P1 | 新公告或经营反馈→差异检测→有意义变化提醒 | 另行授权监控与渠道；去重、频率/费用预算、停止机制先行。 |
| REQ-07 产品内集成 | P1 | 既有项目→证据与机会视图→原流程消费 | 先建立兼容契约和回归；不得用新Skill替换现有方案、资产、反馈、导出能力。 |
| REQ-08 大规模组合优化 | P2 | 多项目历史→相关性/资源冲突分析→分配建议 | 依赖足量同口径数据；不在首版伪造收益分布或优化精度。 |

非目标：自动下单、代客理财、贷款/补贴申请、自动支付、任意爬取私域、绕过网站限制、保证财富增长、把评分称为收益概率、把安装成功称为产品可用或商业成立。

## 主旅程与信息架构

用户入口：说明现有生意与待决策事项 → 得到一页决策简报 → 确认影响分析的约束 → 收集证据并核口径 → 阅读候选及反证 → 复算现金情景 → 选择有预算与停止条件的小试验 → 保存并在反馈后生成新版本。

首版没有独立应用UI，信息架构对应报告章节：决策摘要、业务基线、证据与缺口、候选比较、现金情景、行动卡、附录/版本。未来应用草案沿用既有产品设计系统，文字线框为「顶部决策/截至日，左侧业务与筛选，中部候选比较，右侧证据与反证，底部下一步」。手机版依次为结论→风险→证据→行动，不能仅靠颜色区分事实和假设。报告表格可阅读、标题层级连贯；需要交互时支持键盘、可见焦点、明确状态文案。该线框未做截图、点击或审美验收。

| 情形 | 用户可见结果 | 恢复路径 |
|---|---|---|
| 无经营数据 | 已知/未知清单与有限研究；不输出伪精确回报 | 用户授权后补最少必要数据，保留初版 |
| 来源超时/403/需授权 | 来源、时间和失败原因；可继续的范围 | 官方替代原文或合法人工提供；不绕过访问限制 |
| 财报重述/相反统计 | 原值、新值、口径、受影响结论 | 人工确认可比性后重算，新版本链接旧报告 |
| 线下口头陈述 | COUNTERPARTY_CLAIM，记录对象角色/日期及隐私边界 | 凭据、抽样或实际试验复核；不冒充已独立验证 |
| 工具或会话中断 | 最近完整证据与待办，标记未完成 | 从已保存版本继续；未完成输出不能当最终报告 |
| 用户取消或越预算 | 已有证据与当前费用说明、停止剩余动作 | 显式缩范围或追加授权后续跑 |
| 撤回数据授权 | 停止使用对应材料并报告受影响结论 | 按存储主体实际能力删除/脱敏并生成新报告；不谎称已删除外部备份 |

## 质量目标

北极星：在约定决策窗口内，经营者完成「有来源、有限损、能验证的下一步选择」的合格任务率；分母为所有合格输入的发起任务，包含工具失败。基线未采集，首轮目标见[评测计划](03-evaluation-and-roadmap.md)，目标是待验证门槛。

辅助指标：关键主张可回溯率、严重错引/时点泄漏数、每份报告实际工具/模型/人工成本、自然决策周期中的重复使用。研究时间与资源预算在任务开始登记；未配置费用能力时默认不增加付费服务。隐私采用最小必要数据，私有证据不进入公共仓库；安装与离线算术不需要联网。语义、财务判断和真实价值由实际复核承担，结构检查不能替代。
